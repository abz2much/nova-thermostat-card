# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

`nova-thermostat-card` — a single-file vanilla-JS Home Assistant Lovelace
custom card (HACS category: Dashboard/plugin), part of the same Nova family
as `nova-ha-theme` and `nova-hero-card`. No build step, no dependencies.

## Git and attribution

- Commit and push changes as normal — this repo is meant to stay on GitHub for HACS to install from.
- Never add Claude as a commit author or co-author, and never include a Claude session link in commit messages or PR descriptions — this project's owner has explicitly opted out of that attribution, and it must never appear anywhere in this repo's history, on any branch, at any point — not even transiently before an amend or rewrite. If it's added by mistake, it is not sufficient to amend or rewrite it out afterward — treat that repo as compromised and ask the owner how they want to proceed.
